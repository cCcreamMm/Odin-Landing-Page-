# Landing Page-

A responsive landing page built from scratch as the project for the **CSS & Flexbox** module in [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Overview

This project focuses on translating a full-page design layout into clean semantic HTML and modern CSS, using **Flexbox** as the primary layout engine for alignment, spacing, and multi-section structure.

### Page Sections
- **Header & Navigation:** Logo branding and navigation links aligned with Flexbox.
- **Hero Section:** Main headline, subtext, call-to-action button, and featured image.
- **Information Showcase:** Four-column card grid highlighting key features/items.
- **Quote / Testimonial Section:** Full-width highlight block with styled typography.
- **Call-to-Action Banner:** Centered prompt card encouraging user action.
- **Footer:** Clean copyright and attribution bar.

## Built With

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling, typography, and Box Model spacing
- **CSS Flexbox** — Multi-axis alignment, nested flex containers, and layout distribution
- **Git & GitHub** — Version control and repository hosting

## What I Learned

- Structuring nested flex containers (`flex-direction`, `justify-content`, `align-items`, and `gap`) to build complex multi-row and multi-column layouts without relying on floats or positioning hacks.
- Managing spacing consistency across sections using the CSS Box Model (`margin` and `padding`).
- Breaking down a visual mockup into reusable HTML sections before writing CSS.
