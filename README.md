# Odin-Landing-Page

A digital magazine-style landing page celebrating the Philippines, originally built from scratch for the **CSS & Flexbox** module in [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Overview

This project transforms a classic Flexbox wireframe into an editorial web spread highlighting the Philippines' islands, culture, local food, and hospitality. It focuses on clean semantic HTML, custom typography, and responsive Flexbox alignment.

### Page Sections
- **Header & Navigation:** Magazine title and section links aligned with Flexbox.
- **Hero Section:** Main feature headline, short intro, button, and wide spotlight photo.
- **Information Showcase:** Four-card grid highlighting destinations, food, and culture.
- **Quote Section:** Full-width editorial highlight block.
- **Call-to-Action Banner:** Centered prompt inviting readers to explore more stories.
- **Footer:** Simple copyright bar.

## Built With

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling, typography, and Box Model spacing
- **CSS Flexbox** — Multi-row and multi-column layout alignment
- **Git & GitHub** — Version control and hosting

## What I Learned

- Using nested flex containers (`flex-direction`, `justify-content`, `align-items`, and `gap`) to structure clean multi-section layouts.
- Controlling spacing consistency across sections with the CSS Box Model (`margin` and `padding`).
- Turning a visual wireframe into a themed, real-world webpage.
